# Página de apresentação pessoal

## Objetivo

Criar uma página HTML simples para divulgar o trabalho de Rodolfo Coelho e facilitar o contato por e-mail.

## Público e sucesso

A página é destinada a pessoas interessadas no trabalho do autor. O visitante deve entender que encontrou uma página de apresentação e conseguir iniciar um e-mail para `rodolfopc@gmail.com` com um clique.

## Escopo

- Uma página estática em português, responsiva para celular e desktop.
- Apresentação breve, com linguagem genérica porque ainda não foram fornecidos detalhes sobre a área ou serviços do autor.
- Endereço de e-mail visível e link de contato usando `mailto:rodolfopc@gmail.com`.
- HTML e CSS simples, sem dependências ou JavaScript desnecessários.

## Fora do escopo

- Formulário de contato, backend, analytics ou publicação/hospedagem.
- Afirmações específicas sobre experiência, serviços ou clientes sem informações fornecidas pelo autor.

## Implementação proposta

Como o repositório está vazio, criar `index.html` na raiz do repositório (`rodolfopc.com.br/`). Incluir metadados básicos, estrutura semântica, estilos embutidos e layout acessível com contraste legível, foco visível e adaptação a telas estreitas.

## Verificação

Inspecionar o HTML final para confirmar que o documento está completo, que o e-mail aparece corretamente e que o link `mailto:` aponta para o endereço informado. Não há fluxo de build ou testes existente no repositório.
